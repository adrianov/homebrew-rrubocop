# adrianov/rrubocop

Homebrew tap for [rrubocop](https://github.com/adrianov/rrubocop) — Rust RuboCop drop-in for Ruby.

## Install

```sh
brew install adrianov/rrubocop/rrubocop
```

Or:

```sh
brew tap adrianov/rrubocop
brew install rrubocop
```
